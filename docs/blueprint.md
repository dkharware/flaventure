# **App Name**: ResumeFlow

## Core Features:

- Template Selection: Provide a selection of 35 pre-designed resume and CV templates suitable for various professional fields, built with React and Next.js.
- Data Input and Formatting: Allow users to input and format their personal information, work experience, education, and skills into the selected template.
- AI-Powered Content Suggestions: Offer intelligent suggestions for skills, descriptions, and hobbies based on the user's inputted information and the chosen template; an LLM is used as a tool to help incorporate suggestions where applicable.
- Live Resume Preview: Enable real-time preview of the resume as the user inputs data and customizes the template.
- Download and Export: Provide options to download the completed resume in various formats (PDF, DOCX).

## Style Guidelines:

- Primary color: Slate blue (#708090) to convey professionalism and stability.
- Background color: Light gray (#F0F8FF) for a clean and modern feel, ensuring readability.
- Accent color: Muted olive green (#A9B388), used sparingly for highlighting key actions, progress indicators and elements of the content suggestions feature, to add a touch of understated personality without overwhelming the design.
- Headline font: 'Poppins', sans-serif. Body font: 'PT Sans', sans-serif. This pairing is easy to read in different formats and readable lengths of text.
- Use simple, professional icons for sections like 'Work Experience,' 'Education,' and 'Skills.' Icons should complement the overall minimalist design.
- Maintain a clean and structured layout with clear visual hierarchy. Ensure templates are adaptable and responsive across different screen sizes.
- Incorporate subtle transitions and animations for user interactions, such as expanding sections or loading previews, to enhance the user experience without being distracting.
